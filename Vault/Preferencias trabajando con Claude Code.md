# Preferencias trabajando con Claude Code

Reglas vivas de cómo quiero que Claude se comporte. Claude las lee al iniciar y agrega nuevas cuando lo corrijo (con el porqué).

## Comunicación
- Respuestas directas y cortas. No resumir lo que ya se ve en pantalla.
- Cuando digo "estrictamente" sobre algo, es vinculante: verificar antes de dar por hecho.

## Ejecución
- Operaciones locales y reversibles: ejecutar sin pedir permiso. Confirmar solo antes de acciones destructivas (borrar, push --force, drops de DB, mensajes públicos).
- Tareas con varios pasos: encadenarlos sin pausar entre cada uno.

## Verificación
- Cambios visuales: abrir/revisar el resultado real antes de decir que quedó.
